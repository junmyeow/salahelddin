# صلاح الدين سيرة وأثر

دليل روابط مُنسَّق (Astro + Tailwind) لمواد عن صلاح الدين الأيوبي. الموقع **لا يستضيف** أيّ فيديو أو ملف؛ يخزّن بيانات الفهرسة والروابط الخارجية فقط.

## التشغيل

```bash
npm install
npm run dev          # http://localhost:4321
npm run build        # يبني dist/
npm run preview      # معاينة الناتج
npm run check:links  # يفحص كل الروابط الخارجية
```

## إضافة مادة جديدة

كل شيء في ملف واحد: `src/content/resources.json`. أضف كائناً إلى المصفوفة:

```jsonc
{
  "id": "معرّف-فريد-ثابت",        // لا تغيّره بعد النشر (يصير رابطاً دائماً)
  "title": "العنوان",
  "summary": "سطران على الأقل يشرحان لماذا تستحق هذه المادة الإدراج.",
  "format": "video",              // من FORMATS في src/data/taxonomy.ts
  "language": ["ar"],
  "creator": { "name": "اسم المؤلّف أو القناة", "role": "صفته", "url": "https://…" },
  "publisher": { "name": "الناشر", "url": "https://…" },
  "sourcePlatform": "youtube",    // من PLATFORMS
  "externalUrl": "https://…",     // الرابط الذي يُفتح للزائر
  "embed": { "provider": "youtube", "id": "معرّف-الفيديو", "startAt": 0 },  // أو null
  "thumbnail": null,              // null ⇒ زخرفة مولّدة تلقائياً
  "publishedDate": "2019-06-12",
  "addedDate": "2026-08-16",
  "historical": { "startYear": 1187, "endYear": 1187, "eraId": "hattin-jerusalem" },
  "topics": ["military-campaigns"],  // من TOPICS
  "tags": ["حطين"],
  "rights": { "license": "public-domain" },
  "duration": 22, "pageCount": null,
  "curatorScore": 88,             // ٠–١٠٠ ⇒ يحدّد ترتيب «الأكثر رواجاً»
  "featured": false,
  "status": "live",               // live | broken | pending-review
  "lastChecked": "2026-08-16"
}
```

**التحقّق تلقائي.** المخطّط في `src/content.config.ts` يوقف البناء برسالة واضحة إن نقص حقل أو استُخدمت قيمة خارج المفردات المضبوطة. لا حاجة لاختبار يدوي.

### من أين آتي بمعرّف التضمين؟

| المنصّة | الرابط | `embed.id` |
|---|---|---|
| يوتيوب | `youtube.com/watch?v=**dQw4w9WgXcQ**` | `dQw4w9WgXcQ` |
| ڤيميو | `vimeo.com/**123456789**` | `123456789` |
| أرشيف الإنترنت | `archive.org/details/**saladin00lane**` | `saladin00lane` |

إن لم تكن المادة قابلة للتضمين، ضع `"embed": null` — تظهر البطاقة بزخرفة مولّدة وزرّ خروج فقط.

## كيف يُعتمد اقتراحٌ جديد؟

**لا توجد لوحة تحكّم ولا قاعدة بيانات ولا نشر تلقائي.** الاعتماد يدويّ بالكامل،
وهذا مقصود: هو ما يجعل الموقع مجانيّ الاستضافة وغير قابل للتلويث بمحتوى مُقتحِم.

```
زائر يملأ النموذج
      ↓
Formspree يرسل الاقتراح إلى بريدك   ← لا شيء يظهر على الموقع
      ↓
تقرأ وتقرّر (المحرّر = أنت)
      ↓
تضيف كائناً إلى src/content/resources.json
      ↓
git commit && git push
      ↓
إعادة بناء تلقائية ⇒ يظهر على الموقع بعد نحو دقيقة
```

بدائل تعطيك «طابور مراجعة» مرتّباً بدل صندوق بريد:

| الأداة | المزيّة | العيب |
|---|---|---|
| **Formspree** (المُهيَّأ حالياً) | أسهل إعداد | ٥٠ رسالة/شهر، والطابور هو بريدك |
| **GitHub Issue Forms** | طابور عام بوسوم وحالات، مجاني بلا حدّ | يحتاج الزائر حساب GitHub |
| **Tally** / **Google Forms** | بلا حدّ، ويجمع كل شيء في جدول | يخرج الزائر إلى نطاق آخر |

## توسيع المفردات

- **نوع أو موضوع أو منصّة جديدة** ← `src/data/taxonomy.ts`
- **حقبة تاريخية جديدة** ← `src/content/eras.json`
- **نصوص الموقع والنموذج** ← `src/data/site.ts`

## البنية

```
src/
├─ content/
│  ├─ resources.json      ← الكتالوج (الملف الذي ستحرّره غالباً)
│  └─ eras.json           ← الحقب التي يرسمها الخط الزمني
├─ content.config.ts      ← مخطّط التحقّق (Zod)
├─ data/
│  ├─ taxonomy.ts         ← المفردات المضبوطة + تنسيق الأرقام العربية
│  └─ site.ts             ← إعدادات الموقع والنموذج
├─ components/            ← البطاقة، المرشّحات، الخط الزمني، المشغّل، النافذة
├─ lib/
│  ├─ daily.ts            ← انتقاء «اختيار اليوم» (حتمي، بلا خادم)
│  └─ url.ts              ← بناء الروابط مع مراعاة base
├─ pages/
│  ├─ index.astro         ← الدليل
│  ├─ about.astro         ← المنهجية
│  └─ mawrid/[id].astro   ← صفحة المادة
└─ scripts/directory.ts   ← محرّك البحث والتصفية (يعمل على HTML مرسوم مسبقاً)
```

## اختيار اليوم

لوحة تعرض مادةً واحدة من الأرشيف تتغيّر يومياً. لأن الموقع ثابت، فالانتقاء
**دالةٌ في التاريخ** لا قرارٌ من خادم: `pickIndexForDay()` في
[src/lib/daily.ts](src/lib/daily.ts) يحوّل اليوم التقويمي إلى فهرس.

ضمانان مُختبَران:

- كل مادة تظهر **مرّة واحدة بالضبط** في كل دورة طولها n يوماً (n = عدد المواد)،
  ثم يُعاد خلط الترتيب بالدورة التالية.
- **لا تتكرّر مادة في يومين متتاليين** أبداً (تُعالَج حالة حدّ الدورة صراحةً).

كل زائر في اليوم نفسه يرى المادة نفسها، والتبديل يقع عند منتصف ليل الزائر
المحلي — بلا إعادة بناء وبلا مهامّ مجدولة. تُرسَم اللوحة على الخادم باختيار يوم
البناء (فتعمل بلا جافاسكربت)، ثم يصحّحها سكربتٌ صغير حسب تاريخ الزائر.

لا حمولة إضافية: السكربت يقرأ نفس مصفوفة `#search-index` التي يستعملها البحث.

## ملاحظات تقنية

- **البطاقات مرسومة في HTML**، والسكربت يخفي ويعيد الترتيب فقط ⇒ الموقع كامل ومفهرس حتى بلا جافاسكربت.
- **مشغّلات الفيديو كسولة**: لا يُحمَّل إطار يوتيوب ولا كوكيزه إلا بعد ضغط الزائر على التشغيل.
- **حالة المرشّحات في العنوان** (`?era=…&format=…`) ⇒ الروابط قابلة للمشاركة.
- الحمولة الحالية: ‏٣١ ك.ب جافاسكربت (‏١٢ ك.ب مضغوطة) معظمها محرّك البحث Fuse.js.

## سياسة الإدراج

**لا يُدرَج إلا رابطٌ مُتحقَّق منه ومشروع.** كل مُدخل في الكتالوج جرى فحصه بـ
`npm run check:links` (وبـ `scripts/check-youtube.mjs` لمواد يوتيوب).

ما لا يُدرَج:

- نسخ غير مرخَّصة من كتبٍ ما تزال في الحقوق (مواقع تحميل PDF المقرصنة)
- روابط تحميل مباشرة لملفّات بدل صفحات المصدر
- موادّ محجوبة أو تتطلّب إعارة لا يستطيعها الزائر
- روابط بحثٍ عامّة بدل روابط ثابتة للمادة نفسها

الكتب في الكتالوج إمّا في **الملك العام** أو تحت **رخصة حرّة**، والمواد المرئية
تُعرض عبر مشغّل المنصّة الأصلية مع نسبةٍ كاملة لصاحبها. هذا ما يجعل الموقع
قابلاً للمشاركة بلا حرج.
